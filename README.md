# LIFE — 현실 기반 인생 설계와 시뮬레이션
현실 기준점과 목표, 실행 기록을 관리하는 개인 인생 설계 프로젝트.

**현재: 설계 v0.1 / 과거 기록 기반 프로필 초안 반영 / 현실 기준점 미확정 / 시뮬레이션 미실행.**

[현재 상태 초안](reality/PROFILE_DRAFT.md)을 읽고 달라진 부분부터 수정한다.
기준일 후보: 2026-10-28, 시간대 Asia/Seoul, 통화 KRW.
이 릴리스는 운영 가능한 문서 체계다. 재무 계산 프로그램·자동 에이전트·대시보드는 아직 구현하지 않았다.

## 먼저 읽기
1. [전체 설계](docs/MASTER_PLAN.md)
2. [운영 프롬프트](prompts/MASTER_PROMPT.md)
3. [진행 현황과 다음 행동](state/STATUS.md)
4. [TURN 1 조사 안내](intake/README.md)
5. [개발 로드맵](docs/ROADMAP.md)

## 핵심 흐름
조사 → 근거 정리 → 모순 확인 → 현실 기준점 확정 → 경로 비교 → 분기 시뮬레이션 → 실제 실행 → 재평가.
현실은 reality, 가상 결과는 simulation에 기록한다. 가상 결과로 현실을 덮어쓰지 않는다.

## 사용 방법
새 대화에서 “LIFE 저장소의 AGENTS.md, state/STATUS.md, prompts/MASTER_PROMPT.md를 읽고 이어서 진행해줘”라고 요청한다.
대화에 저장소 접근이 없다면 접근 가능한 파일을 제공한 범위에서만 진행한다.
명령 목록은 [워크플로](docs/WORKFLOWS.md)의 대화용 명령이다. 설치된 CLI나 예약 자동화가 아니다.

## 이번 릴리스의 범위
- 9개 조사 영역, 역할별 검토 책임, 단계 전환 기준.
- 자금·부채·시간 계산 명세와 테스트 요구사항.
- 2036년까지 분기 시뮬레이션, 90일 실행, 주간·월간 검토 설계.
- 과거 진술과 저장소 관측을 출처별 draft 후보로 입력했다. 현재 값 확정 전이며 게임 저장값은 제외했다.
- 원본 증빙·인증정보·불필요한 식별정보는 저장하지 않는다.
