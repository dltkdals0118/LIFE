# 입력함 — 한 달에 한 줄이면 된다

작성: WACUS

## 한 줄

```
2026-11-30    cash    4200000
```

**이게 전부다.** 현금 잔액 하나만 적으면 나머지는 빼기로 나온다 —
`7/30 1,400만 → 10/31 500만` 두 점만으로 **매달 294만 줄어든다**가 계산됐다.
가계부를 옮겨 적지 않았다.

적고 **커밋하면 끝이다.** 훅이 돌면서 사실을 넣고, `state/NOW.md`(지금)와
`simulation/FORECAST.md`(앞으로 6달 · 경우의 수 · 협상 목표)를 다시 쓴다.

> 사용자 지시 2026-11-09: *"다 안 적을거야. 매번 이렇게 가계부를 적어야 하면 너무 힘들어."*
> **맞는 지적이라 이렇게 바꿨다.** 입력이 많으면 안 적게 되고, 안 적으면 시뮬레이션이 멈춘다.

## 안 적어도 되는 것

| | |
|---|---|
| **가계부 전체** | 안 적는다. 현금 잔액 차이로 흐름이 나온다 |
| 매일 기록 | 안 해도 된다. **20일 이상 떨어진 두 점**이면 월 흐름이 나온다 |
| 모르는 값 | **비워 둔다.** 0 으로 적지 않는다 — 0 은 "0 이라고 쟀다"는 뜻이다 |

## 가끔 적으면 좋은 것 (안 적어도 돌아간다)

| 항목 | 언제 | 왜 |
|---|---|---|
| `debt` | 두어 달에 한 번 | **대출을 새로 받으면 현금이 늘어 적자가 가려진다.** 이것만 막아 준다 |
| `income` | 바뀔 때만 | 승진·협상 뒤 |
| `late` | 생각날 때 | 지각이 입지에 걸려 있다(FACT-0199). 수면과 같이 보면 연결이 보인다 |

## 스크린샷이 더 편하면

가계부 앱 화면을 **대화에 붙여넣으면** 내가 읽어서 이 파일에 한 줄로 적고 커밋한다.
전에도 그렇게 했다(10월 소비분석 5장 → FACT-0182). **본인이 타이핑할 필요가 없다.**

## 형식

칸은 **탭 또는 공백 2칸 이상**으로 나눈다. `#` 로 시작하면 주석이다.

```
날짜          항목    값        메모(선택)
2026-11-30    cash    4200000   월말 확인
```

항목 이름 — 모르는 이름은 **조용히 무시하지 않고 행 번호와 함께 막는다.**

| 묶음 | 항목 | 단위 |
|---|---|---|
| 돈 | **`cash`** `spend` `inflow` `debt` `debt_payment` `income` `rate` | 원 (rate 는 %) |
| 포커 | `poker-out` `poker-in` `poker-hours` | 원 / 원 / 시간 |
| 몸 | `sleep` `weight` `exercise` `steps` `mood` | 시간 / kg / 분 / 걸음 / 1~5 |
| 시간·배움 | `hours` `study` | 시간 / 분 |
| 일 | `late` | 회 |
| 집 | `rent` | 원 |
| 이직 | `offer_net` | 원 |

## 지켜지는 것

- **같은 줄을 두 번 반영하지 않는다.** `.applied.json` 이 기억한다. 줄을 지워도 사실은 남는다.
- **파생값은 `reality/` 에 들어가지 않는다.** 계약상 `simulated` 는 `simulation/` 전용이다.
- **엔진은 판정하지 않는다.** 숫자와 "왜 못 구했는지"만 낸다. 좋다·나쁘다를 적지 않는다.
- **20일 미만으로 떨어진 두 점으로는 월 흐름을 내지 않는다.** 사흘 간격으로 "매달 500만 줄었다"가 나온 적이 있다.
