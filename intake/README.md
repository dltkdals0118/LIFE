# TURN 1 — 정밀 조사
현재 실제 답변은 아직 기록하지 않았다. 아래는 질문 은행이며 한 번에 모두 묻지 않는다.

## 첫 질문 묶음
1. 현재 나이·주거 형태·동거/부양 관계는?
2. 같은 날짜 기준 즉시 사용 가능한 현금과 별도 자산은?
3. 대출별 잔액·금리·납입액·만기·상환방식은? 모르는 조건은 모름으로 적기.
4. 현재 직장·고용형태·세후 수입과 최근 3개월 부수입 입금액은?
5. 월 필수 생활비·가족 지원·취미비는? 상환액은 따로 표시.
6. 12개월 이내 반드시 필요한 목돈·기한은?
7. 최근 2주 수면·근무·통근 시간과 실제 생활에서 어려운 일은?
8. 2036년에 원하는 삶, 반드시 지킬 것, 가장 먼저 바꿀 것은?

## 답변 처리
FACT 후보 작성 → source 연결 → 단위/날짜 확인 → 충돌 기록 → 다음 질문.
정확한 숫자를 모르면 범위를 기록하고 결정 영향이 큰 부분만 재확인한다.
증빙 요청은 수치 차이를 해결하는 최소 항목으로 제한하고 식별정보를 가린 상태를 권한다.
모든 질문의 답변이 기준점 확정의 필수 조건은 아니다.
