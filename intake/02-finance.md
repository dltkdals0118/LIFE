# 자산·부채·현금흐름·필요 자금
목적: 같은 날짜의 재무 기준점을 만든다.
상태: 질문 은행 / 미응답. 한 번에 5~8개만 선택한다.

## 질문
1. 현재 현금·입출금통장·예적금·투자자산·보증금은 각각 얼마이며 소유자는 누구인가?
2. 즉시 쓸 수 없는 돈과 인출/매각 비용·예정일은?
3. 대출마다 잔액·금리·고정/변동·원리금·납입일·만기·상환방식은?
4. 카드 미결제·할부·가족/지인 채무·보증 의무·연체는?
5. 최근 3개월 세후 급여와 변동수입의 실제 입금액은? 일회성/반복성을 구분하면?
6. 월 고정비와 변동비, 연간 비용·세금·병원비·가족지원·취미비는?
7. 향후 12개월 목돈의 용도·필수 여부·금액·기한은?
8. 월초/월말 잔액과 수입-지출의 차이는 얼마이며 설명되지 않는 차이가 있는가?
9. 사용자가 지키고 싶은 최소 현금과 감당할 수 있는 월 지출 수준은?

## 확인할 오류
자산과 현금 구분, 원금/이자, 카드 이중계상, 내부 이체, 본인/가구, 세전/세후.

## 다른 영역과 연결
필요자금→목표, 부수입→역량, 취미→변동성 활동.

## 기록 방법
각 답변의 기준일·단위·근거·kind를 남긴다. 미확인과 보류는 구분한다.
답변을 받은 뒤 확인한 내용 / 모순 / 다음 질문 3부분으로 정리한다.
