# 목표·꿈·가치와 필요한 돈
목적: 본인이 원하는 삶을 비용·시간·선행 조건과 연결한다.
상태: 질문 은행 / 미응답. 한 번에 5~8개만 선택한다.

## 질문
1. 2036년 평범한 하루를 어디서 누구와 무엇을 하며 보내고 싶은가?
2. 돈·일·건강·관계·자유·창작 중 지금 우선순위는 무엇이며 이유는?
3. 1년/3년/10년에 이루고 싶은 상태를 최소 만족과 희망 수준으로 나누면?
4. 목표별 기한과 일회/반복 비용은 얼마이며 어떤 근거가 있는가?
5. 가장 중요한 목표 3개와 서로 충돌하는 부분은?
6. 절대 포기하고 싶지 않은 것과 줄일 수 있는 것은?
7. 본인 욕구와 가족·사회·비교 대상의 기대가 섞인 목표는?
8. 실패했어도 시도한 가치가 있을 꿈, 작은 실험으로 확인할 꿈은?

## 확인할 오류
목표를 분석자가 대리 결정하지 않음; 명목/실질 돈과 기한; 필수/희망 지출 구분.

## 다른 영역과 연결
목표→필요자금, 꿈→역량 실험, 가치→경로 평가.

## 기록 방법
각 답변의 기준일·단위·근거·kind를 남긴다. 미확인과 보류는 구분한다.
답변을 받은 뒤 확인한 내용 / 모순 / 다음 질문 3부분으로 정리한다.
