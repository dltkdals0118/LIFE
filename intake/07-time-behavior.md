# 시간·습관·실행 패턴
목적: 희망 계획보다 실제 행동을 기준으로 자원량을 잡는다.
상태: 질문 은행 / 미응답. 한 번에 5~8개만 선택한다.

## 질문
1. 최근 평일 2일과 주말 1일의 시간 사용을 수면부터 순서대로 적으면?
2. 근무·통근·식사·가사·돌봄·회복 후 남는 시간은?
3. 공부·부업 계획과 실제 실행 시간은 얼마나 달랐는가?
4. 계획이 무너지는 상황과 그 직전에 하는 행동은?
5. 미루기·소비·과몰입이 늘어나는 시간/감정/환경은?
6. 잘 지켰던 계획의 크기·시간·도움 조건은?
7. 주간 기록에 실제로 쓸 수 있는 시간과 부담스러운 방식은?
8. 계획을 절반만 실행해도 유지할 최소 행동은?

## 확인할 오류
주 168시간 초과, 중복시간, 통근 중 집중시간 과대평가, 회복 누락.

## 다른 영역과 연결
시간→학습/부업, 유발 상황→지출, 기록 부담→운영.

## 기록 방법
각 답변의 기준일·단위·근거·kind를 남긴다. 미확인과 보류는 구분한다.
답변을 받은 뒤 확인한 내용 / 모순 / 다음 질문 3부분으로 정리한다.
