# 이직 — 제안이 왔고, 전제가 흔들렸다

작성: WACUS · 2026-11-04 · 근거 FACT-0195(제안) · FACT-0196(입지) · FACT-0197(산술) · SRC-121

> *"매드코퍼레이션에서 포지션 제안이 왔고 현재 회사에서 내 입지가 안 좋은 상태야."*

## 0. 먼저 — 두 번째 문장이 더 크다

제안은 **선택지가 하나 는 것**이고, 입지는 **전제가 흔들린 것**이다.

**지금까지 쓴 모든 문서가 '세후 260만이 2027년까지 유지된다'를 깔고 있다:**

| 문서 | 무엇을 전제했나 |
|---|---|
`STABILIZE_20261029.md` | 런웨이 5.1개월 · 적자 117만 — **소득 260만이 들어온다는 가정** |
`UNIVERSITY_20261103.md` | A(전업)는 저축이 선행, B(병행)는 직장 유지 — **둘 다 소득 전제** |
`LAST_RESORT_20261103.md` | 개인회생은 **가용소득이 있어야 인가된다** |

**소득이 끊기면 세 문서가 동시에 무효가 된다.**

## 1. 숫자 — 소득이 끊기는 경우가 압도적으로 비싸다

| 상황 | 월 유출 | 현금 500만으로 |
|---|---:|---:|
| 소득 유지 (지금) | 적자 2,650,000 | **1.9개월** |
| 소득 유지 + 148만 절감 | 적자 1,170,000 | 5.1개월 |
| **소득 중단** | **5,250,000** | **1.0개월** |

그리고 소득이 끊기면 **개인회생 경로까지 막힌다** — 가용소득이 없으면 변제계획을 세울 수 없어
3단(개인회생)이 아니라 4단(파산)으로 간다. 거기서는 포커 쟁점이 가장 크게 작용한다(LAST_RESORT §4).

> **가장 비싼 선택은 제안을 흘려보내고, 입지가 더 나빠진 뒤 무직으로 나오는 것이다.**
> 런웨이 1.0개월에 안전망까지 막힌 자리다. 이건 피해야 할 **하나**가 분명하다.

## 2. 이직을 '적자 0'의 수단으로 본다면 기준선

STABILIZE 는 **레버를 전부 써도 117만이 남는다**고 결론냈다(§4). 그 부족분을 급여로 메우려면:

```
필요 세후 월 = 2,600,000 + 1,170,000 = 3,770,000원
            → 연 세후 45,240,000  → 세전 대략 5,300만원대 (공제율 가정 · 추정)
```

현재 예상 세전 4,000만(FACT-0140) 대비 **+1,400만 이상**이다.

- **세후 377만 이상** → 이직만으로 적자 0 사정권.
- **그 아래** → 이직해도 적자는 남고, 지출·포커·주거 레버가 **여전히 전부 필요하다.**

**다만 이직의 목적이 적자 0 하나는 아니다.** 입지 위험을 없애는 것 자체가 값이고,
그건 숫자로 환산하지 않았다 — 환산할 근거가 없다.

## 2-1. 답이 온 뒤 (2026-11-04 갱신 · SRC-122)

> *"오퍼야. 직무는 SEO / GEO 팀원"* · *"그런 건 아닌데, 최근에 지각도 좀 했었고 일을 잘 못한 부분도 있어서 위에서 좋게 보진 않아."*

**두 가지가 분명해졌고 둘 다 좋은 쪽이다.**

| | |
|---|---|
| **오퍼다** | 타진·면접이 아니다. **결정 창이 이미 열려 있고 오퍼에는 보통 회신 기한이 있다**(미확인) |
| **SEO / GEO** | 본인 핵심 역량과 정확히 겹친다(FACT-0001·0151). GEO 는 커지는 영역이라 경력이 이어진다 |
| **공식 조치 없음** | 권고사직·PIP·계약종료 모두 아니다. **시한이 없고 되돌릴 수 있는 종류다** |

→ **B('남는다 + 조건을 바꾼다')의 성립 조건이 충족됐다.** 입지는 회복 가능하다.

**다만 범위는 좁아진다.** 지금은 마케팅 4팀 대리로 웹블로그 발행·자동화 구축·TF·웹앱 기획까지 한다(FACT-0187).
SEO/GEO 팀원이면 **집중이 되거나 폭이 줄거나** 둘 중 하나다. 어느 쪽인지는 조건을 봐야 안다.
**'팀원'이 직급 변화를 뜻하는지도 미확인.**

## 2-2. 원인이 행동이면 **이직이 해결하지 않는다**

입지가 나쁜 이유가 **지각과 업무**다. 이건 사람이 아니라 **같이 옮겨 다니는 조건**이다 —
새 회사에서 같은 패턴이면 6개월 뒤 같은 자리다. **그래서 교정은 A·B 공통 전제다.**

**다만 의지 문제로 환원하지 않는다.** 깔려 있는 것이 있다:

| | 근거 |
|---|---|
| 수면 장애 **치료 중** — 복용에도 입면·유지·이른 기상 어려움 | FACT-0013 |
| **낮 졸림 지속** | FACT-0075 계열 |
| 새벽 각성 후 재입면 실패 + **포커 딥런으로 수면 회복 기회 상실** | FACT-0014 |
| 하루에 포커 4~5시간 | FACT-0096·0097 |

**셋 중 무엇이 얼마나 기여하는지는 모른다.** 치료 영역(수면 장애)과 조절 가능한 부분(포커 딥런)을 **갈라서** 봐야 하고,
전자는 우리 자격 밖이다(H2). **인과를 단정하지 않는다 — 측정한다**: 지각 횟수와 수면 시간을 같이 적으면 몇 주 안에 보인다.

**바뀐 것은 성격이다. 수면이 '건강' 문제에서 '소득' 문제가 됐다.**
`plan-sleep` 은 이제 G4 만이 아니라 **직장 유지의 전제**다.
그리고 **이건 다음 진료 때 전할 정보다** — 증상이 출근에 영향을 주기 시작했다는 것은 치료를 보는 쪽이 알아야 할 변화다.

## 3. 아직 모르는 것 — **세후 월급 하나가 결정을 막고 있다**

**제안에 대해 아는 것이 이름뿐이다.**

| 모르는 것 | 왜 필요한가 |
|---|---|
| **세후 월급** | §2 의 **377만** 선과 바로 비교된다. **이거 하나가 A/B 를 가른다** |
| **회신 기한** | 오퍼에는 기한이 있다. 지나면 선택지가 사라진다 |
| 고용형태 | 정규/계약/수습 — 계약직이면 런웨이 계산이 또 달라진다 |
| 입사 시점 | 공백이 생기는지. **공백 한 달 = 현금 525만**이다 |
| 직급 | '팀원'이 대리에서 내려가는 것인지 |

→ `D-009` 의 남은 부분. **추정으로 채우지 않았다.**

## 4. 경로 세 가지

| | 무엇 | 성립 조건 | 포기하는 것 |
|---|---|---|---|
| **A 간다** | SEO/GEO 팀원 (오퍼) | 세후 **377만 이상**이면 적자 0 사정권 | DX 11월 성과 · 사내 맥락 · 업무 폭 |
| **B 남는다 + 조건을 바꾼다** | DX 11월 성과 → 2027-01 협상 | **충족됨** — 공식 조치가 없어 회복 가능하다 | 오퍼. 다시 안 올 수 있다 |
| **C 조건을 받아본다** *(지금)* | 면접·오퍼로 숫자를 확정 | 아무것도 포기하지 않는다 | 시간. 그리고 회사에 알려질 위험 |

**둘 다 열려 있다 — 그런데 세후 월급을 모른다.** C 가 지금인 이유는 그것뿐이고, **C 는 A·B 중 무엇도 닫지 않는다.**
다만 **C 에 머무는 기간은 공짜가 아니다** — 입지가 나빠지는 속도가 변수다.

## 5. DX 11월 마감이 여기에 걸린다

11/02 배정된 AI 주간보고서 자동화는 **1차 기간이 11월**이다(FACT-0187).

- **B 를 고른다면** 이건 입지를 바꿀 가장 가까운 기회다. 시한이 짧고 결과가 눈에 보이는 일이다.
- **A 를 고른다면** 인수인계 범위가 된다.
- 어느 쪽이든 **지금 손을 놓는 선택지는 없다** — 놓으면 B 가 사라지고 A 의 협상력도 깎인다.

## 6. 바뀌지 않는 것

**지출 절감은 그대로 1순위다.** 오히려 더 급해졌다 —
런웨이를 1.9 → 5.1개월로 늘리는 것이 **결정을 서두르지 않아도 되게 만드는 유일한 수단**이다.
현금이 한 달치면 조건을 따질 여유가 없어지고, 그때는 제안을 **고르는 것이 아니라 받아야** 한다.

## 7. 공통으로 해야 하는 것 — A 를 고르든 B 를 고르든

1. **세후 월급과 회신 기한을 받는다** (11/07). 이게 없으면 아무것도 못 고른다.
2. **지각을 멈춘다.** 옮겨 다니는 조건이라 A 에서도 따라간다. 지각 횟수를 수면과 **같이** 적는다(주간).
3. **DX 를 놓지 않는다.** B 면 회복의 기회, A 면 인수인계 범위. 놓으면 B 가 사라지고 A 의 협상력도 깎인다.
4. **지출을 줄인다.** 런웨이 5.1개월이 **조건을 따질 여유**를 만든다.

> **이 문서가 하지 않은 것**: 매드코퍼레이션을 조사하지 않았고, 오퍼의 좋고 나쁨을 판단하지 않았다.
> **지각과 수면의 인과를 단정하지 않았다** — 측정된 적이 없다. 수면 장애는 치료 중이고 우리 자격 밖이다(H2).
