# 지출만으로 어디까지 가나 — 2026-10-29

작성: WACUS · 근거 SRC-048(FACT-0169) · 기준점 [BASE-20261028-v1](../reality/baselines/BASE-20261028-v1.md)
결정 [DEC-001](../decisions/DEC-001-expense-first.md)

**사용자 지시**: *"지금은 지출이 많이 큰 상황이니까 큰 목표보다 우선 지출을 줄이고 생활 안정화 시킬 수 있는 방향으로 가자."*

이 문서는 **그 방향으로 갈 때 어디까지 닿는지**만 센다. 산술이고 권고가 아니다.

**2026-10-29 갱신 (SRC-049)**: '생활 안정화'의 기준이 **적자 0 + 수면·건강**으로 확정됐다(FACT-0170).
주거 계약 만료는 **2027-04**(FACT-0171), 채무 금리는 **7.8%대**(FACT-0172).
→ 4~6절이 **추정에서 실수치로 바뀌었다.** 결정 [DEC-002](../decisions/DEC-002-stabilization-target.md).

## 1. 실측 두 개로 시작한다
가계부 분해를 쓰지 않는다 — '이체' 안에 무엇이 들었는지 모르기 때문이다(FACT-0105, 본인 보류).
**가장 믿을 수 있는 값 둘만 쓴다.**

| | 값 | 근거 |
|---|---:|---|
| 월 수입 | 280~290만 (중앙값 **285만**) | 급여 260 세후 + 인센티브 20~30 (FACT-0060·0061) |
| 월 현금 감소 | 약 **267만** | 1,400만(7/30) → 600만(10/28), 3개월 (FACT-0101) |
| **월 총유출** | **약 552만** | 수입 + 현금 감소 |

**교차 검증**: 가계부 10월 실지출(합계−이체)이 549만이다(FACT-0116). **2.2% 안에서 맞는다**(FACT-0117).
서로 다른 두 방법이 같은 값을 가리킨다 — **총유출 약 550만은 믿을 수 있는 숫자다.**

## 2. 줄일 수 있는 것과 없는 것
확인된 고정 유출은 239만이다(FACT-0063~0066·0077~0080). **성질이 셋으로 갈린다.**

| 성질 | 항목 | 월액 | 왜 그렇게 분류하나 |
|---|---|---:|---|
| **단기에 못 줄인다** | 채무 상환 | 80만 | 약 6년 자연 완제. 조기상환엔 4,600만이 먼저 필요한 순환(FACT-0147) |
| | 주거비 | 95만 | 2026-04 입주. **계약 기간 미확인** — 이사는 2단계(FACT-0148) |
| **한 번 정하면 끝난다** | 통신 | 7만 | 요금제 전환. **의지가 매달 들지 않는다** |
| | 보험 | 10만 | 보장 점검. 금융 판단이라 **공식 근거 확인 후**(AGENTS.md) |
| | 청약 | 10만 | **저축이지 소비가 아니다.** 줄이면 현금흐름은 늘고 주거 목표는 늦어진다 — 본인 선택 |
| **매달 의지가 든다** | 식음료 | **281만** | 최대 항목. 카페·간식 141 + 식비 139 (10월 1~28, FACT-0093) |
| | 쇼핑·그 외 | 미확인 | 가계부 상세 보류 |
| | 어머니 지원 | 30만 | 가족 의무. **절감 항목으로 올리지 않는다** |
| | 포커 바이인 | 약 70만(추정) | 통장 순유출 ASM-0024. 본인이 40만 축소 발의(FACT-0162). 포커는 불가침(FACT-0122) |

### 여기서 나오는 구분 하나
**안정화란 의지에 덜 의존하는 상태다.**
- '한 번 정하면 끝나는 것'은 통신 7 + 보험 10 = **약 17만**뿐이다. 100만을 못 만든다.
- 100만의 대부분은 **매달 싸워야 하는 쪽**(식음료·쇼핑·바이인)에서 나온다.

→ **둘 다 필요하다.** 17만은 작지만 영구적이고, 식음료는 크지만 매달 유지해야 한다.
→ 그래서 **한 번 끝나는 것을 먼저 치운다.** 작아도 그 뒤로는 관리 비용이 0 이다.

## 3. 사다리 — 월 절감액과 런웨이
현금 600만 기준(10/28, FACT-0062). **퇴직금 300만은 넣지 않았다**(퇴사 2027-01~03, FACT-0086·0104).

| 월 절감 | 적자 | 런웨이 | 무엇을 줄이면 거기 가나 |
|---:|---:|---:|---|
| 0 | 265만 | **2.3개월** | 지금 |
| 50만 | 215만 | 2.8개월 | 본인이 '가능하다'고 먼저 말한 선 (FACT-0144) |
| **100만** | **165만** | **3.6개월** | 현재 목표. 식비30+쇼핑30+바이인40 (FACT-0167) |
| 150만 | 115만 | 5.2개월 | 100만 목표 + 식음료에서 50만 더 |
| 200만 | 65만 | 9.2개월 | 100만 목표 + 식음료에서 100만 더 + 고정비 정리 |
| **265만** | **0** | — | 식음료를 **281 → 약 60만** + 바이인 40만. 본인이 '비현실적'이라 한 영역(FACT-0139) |

**런웨이는 절감액에 선형으로 늘지 않는다.** 100 → 150만(50만 추가)이 1.6개월을 더 사는데,
150 → 200만(같은 50만)은 **4.0개월**을 더 산다. 적자가 작아질수록 같은 50만이 더 길게 산다.
→ **100만에서 멈추는 것과 150만까지 가는 것의 차이가 생각보다 크다.** 관측이다.

## 4. 적자 0 까지의 경로 — 레버를 전부 더해 본다
안정화 기준이 **적자 0** 으로 확정됐다(FACT-0170). 그러면 필요한 것은 **월 265만**이다.
**쓸 수 있는 레버를 전부 더한다.**

| 레버 | 월 효과 | 근거 | 언제 |
|---|---:|---|---|
| 지출 절감 | **100만** | FACT-0157·0167, 본인 확인 | 11월부터 |
| 통신 + 보험 정리 | **약 17만** | FACT-0078·0080. 한 번 정하면 끝난다 | 11월 |
| 채무 금리 전환 (7.8 → 5.0%) | **약 6만** | FACT-0172 실계산. 기간 72개월 유지 기준 | 조건 확인 후 |
| 주거 이사 (2027-04 만료) | **가정 25만** | FACT-0171. **실제 폭은 매물을 봐야 안다 — 가정이다** | 2027-04 |
| **합계** | **약 148만** | | |
| **남는 적자** | **약 117만** | | |

**전부 해도 117만이 남는다.** 런웨이는 2.3 → **5.1개월**로 늘지만 적자는 0 이 되지 않는다.

→ **적자 0 을 목표로 택하면 수입은 선택이 아니라 필수다.** 월 **약 117만**이 필요하다
  (주거 25만 가정을 빼면 **142만**). 건당 100만이면 **월 1.2~1.4건**이다.

**'지출 먼저'(FACT-0169)와 충돌하지 않는다** — 하나는 **목적지**이고 하나는 **순서**다.
지출·고정비는 **지금 할 수 있고 시간이 거의 들지 않는다**(행동 대부분 10분 이하).
수입 축은 시간이 드니 뒤에 온다. **다만 "결국 필요하다"를 적어 두지 않으면 목적지가 사라진다.**

### 채무 금리를 따로 보는 이유 — 월 효과와 총액 효과가 다르다
잔액 4,600만 · 월 납입 80만 · **7.8%** → **월 이자 29.9만 / 원금 50.1만.** 납입액의 **37%가 이자**다.

| 금리 | 월 납입 (72개월 유지) | 월 절감 | 총이자 |
|---:|---:|---:|---:|
| **7.8%** (현재) | 80.0만 | — | **1,175만** |
| 6.0% | 76.2만 | 3.8만 | 889만 |
| 5.0% | 74.1만 | **5.9만** | **734만** |
| 4.0% | 72.0만 | 8.0만 | 582만 |

**월 현금흐름 효과는 4~8만으로 작고, 총이자 효과는 286~593만으로 크다.** 둘을 섞지 않는다.
런웨이를 늘리는 것은 앞쪽이고, 6년 뒤 자산을 바꾸는 것은 뒤쪽이다.

**금융 판단은 하지 않는다**(AGENTS.md). 전환 가능성은 대출 종류·고정변동·중도상환수수료·신용 조건에 달렸고
**전부 미확인이다.** 이 표는 "조건을 확인할 가치가 있나"에만 답한다 — **있다.**

### 주거가 가장 큰 레버이고 결정 시점이 90일 안에 있다
월 95만은 확인 고정비 239만의 **40%** 다. 그런데 계약이 **2027-04** 에 만료된다(FACT-0171).

통상 재계약·이사는 만료 **2~3개월 전**에 정해야 한다(**근거: 미확인** — 계약서 조항과 법정 통보 기한을 확인할 것).
→ 결정 시점이 **2027-01~02** 이고, **90일 계획 종료일이 2027-01-27 이다.**

**즉 이번 90일의 숨은 산출물은 "4월 이사 결정에 필요한 정보"다.**
한 번 정하면 2년이 결정되고, 월 95만의 어느 부분이 줄어드는지가 적자 117만에 직접 들어간다.

제약: 통근 왕복 1시간 미만(FACT-0067·0068) · 보증금 2,000만은 묶여 있고 **증액 여력 없음**(현금 600만)
· 이사 비용·중개수수료 **미확인**. **월세 절감폭은 지어내지 않는다** — 매물을 봐야 안다.

| 시점 | 무엇 | 근거 |
|---|---|---|
| 2027-01 | 연봉협상 — 세전 4,000만. **현재 세후와 거의 같다** | FACT-0140 |
| 2027-01~03 | 퇴사·이직 (공식 통보 전, 오퍼 없음). 퇴직금 약 300만 | FACT-0086·0104 |
| 2027-01~02 | **주거 재계약·이사 결정** | FACT-0171 |

**네 개가 같은 분기에 몰려 있고, 그 분기가 90일 계획이 끝나는 지점이다.**
**이번 90일의 목적은 그 분기에 선택지를 가진 채로 들어가는 것이다.** 관측이고 지시가 아니다.

## 6. 수면·건강 — 이제 목표에 들어왔다
안정화 기준에 **수면·건강**이 포함됐다(FACT-0170). 그러면 **시간이 목표 변수가 된다.**

하루가 **21.7~22.7시간** 차 있다 — 수면 7.2 + 근무 9.5 + 통근 1 + 포커 4~5(FACT-0096·0097).
낮 졸림이 지속 중이고(FACT-0074) 두통·어지럼이 간헐적이며 처방약 복용 중이다(FACT-0075·0076).

| 칸 | 바꿀 수 있나 |
|---|---|
| 근무 9.5h · 통근 1h | 고정 (퇴사·이직 전까지) |
| 포커 4~5h | **불가침 제약**(FACT-0122). 제안하지 않는다 |
| 부업 | **쓰지 않으면 주 7.9~9.9시간이 남는다** |

→ **수면을 늘릴 여지는 '부업 시간을 쓰지 않는 것'에서 나온다.**
→ 그런데 **적자 0 은 수입 117만을 요구한다.** **두 목표가 서로 당긴다.**

**평균내지 않는다.** 지금 90일에는 **충돌하지 않는다** — 지출·고정비 행동은 대부분 10분 이하다.
**충돌은 수입 축을 올리는 시점의 문제**이고, 그때 선택지를 둘로 적어 올린다.

**목표 수치는 정하지 않았다.** 수면 몇 시간·증상 빈도 얼마가 '안정'인지는 본인이 정한다.
기록 틀만 세웠다([trackers/G4-stability.md](../execution/trackers/G4-stability.md)).
**의학 판단·약물 변경을 이 문서의 결론으로 삼지 않는다**(AGENTS.md).

## 7. 부수 효과 — 시간이 돌아온다
G2 를 90일 필수 목표에서 빼면 **주 7.9~9.9시간이 빈다**(생산 4.9 + 영업 3~5, FACT-0166).

하루가 21.7~22.7시간 차 있었다 — 수면 7.2 + 근무 9.5 + 통근 1 + 포커 4~5(FACT-0096·0097).
**그 7.9~9.9시간은 수면·회복으로 돌아갈 수 있다.** 낮 졸림이 지속 중이고(FACT-0074) 두통·어지럼이 간헐적이다(FACT-0075).

**관측이고 지시가 아니다.** 어디에 쓸지는 본인이 정한다. 포커는 불가침이라 건드리지 않는다.

## 8. 측정 — 가장 싼 지표 하나
**월말 현금 잔액 한 칸이 이 문서 전체를 매달 실측으로 바꾼다.**

적자 추정은 지금 월 206~301만 구간이다(FACT-0117). 구간이 넓은 이유는 가계부 상세가 없기 때문인데,
**현금 잔액은 상세가 필요 없다** — 가계부든 포커든 이체든 전부 거기 나타난다.

| 지표 | 비용 | 무엇을 재나 |
|---|---|---|
| **월말 현금 잔액** | 월 1분 | **적자 실측.** 구간 206~301만을 숫자 하나로 대체 |
| 실지출 (합계−이체) | 월 10분 | 소비 쪽 절감 — 식비·쇼핑 60만 |
| 포커 통장 순유출 | 월 5분 | 바이인 쪽 절감 — 40만. **실지출에는 안 나타난다**(이체로 분류될 가능성) |

**셋을 따로 재야 한다.** 100만 절감의 60%와 40%가 서로 다른 지표에 나타나기 때문이다.
기록은 [`execution/trackers/`](../execution/trackers/).
