# 열린 질문
질문은 중요도에 따라 한 번에 5~8개로 묶어 진행한다.

| ID | 미확인 | 영향 | 상태 |
|---|---|---|---|
| Q-001 | 현실 기준일과 현재 생활·부양 관계 | 모든 기준점 | 미응답 |
| Q-002 | 사용 가능한 현금·별도 자산 | 자금 여력 | 미응답 |
| Q-003 | 대출·카드·개인채무 상세 | 상환·만기 | 미응답 |
| Q-004 | 세후 수입·변동수입 | 월 현금흐름 | 미응답 |
| Q-005 | 필수비·비정기비·필요 목돈 | 부족 시점 | 미응답 |
| Q-006 | 수면·근무·통근·생활 기능 | 실행 여력 | 미응답 |
| Q-007 | 역량 증거·직장 입지 | 이직·부업 조건 | 후속 조사 |
| Q-008 | 가정 의무·지지·경계 | 선택 제약 | 후속 조사 |
| Q-009 | 목표·꿈·우선순위 | 경로 비교 | 미응답 |
| Q-010 | 포커 등 활동의 현재 여부·기록 | 변동손익·시간 | 후속 조사 |

개인 질문과 기술 구현 과제는 분리한다. 기술 과제는 docs/ROADMAP.md에 있다.
