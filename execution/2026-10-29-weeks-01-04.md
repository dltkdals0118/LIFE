# 첫 4주 행동 — 2026-10-29(목) ~ 2026-11-28(토)

작성: WACUS · 근거 [90일 실행 계획](2026-10-29-plan-90days.md) · 결정 [DEC-001](../decisions/DEC-001-expense-first.md)
산술 [STABILIZE](../simulation/STABILIZE_20261029.md)

**2026-10-29 우선순위가 바뀌었다** — 지출 축소·생활 안정화가 1순위, 유상 거래(G2)는 후순위.
그래서 이 4주는 **지출·고정비·기록**이 전부다. 영업은 들어 있지 않다.

**같은 날 안정화의 기준이 확정됐다** — **적자 0 + 수면·건강**([DEC-002](../decisions/DEC-002-stabilization-target.md) · FACT-0170).
그래서 둘이 더 들어왔다: **수면 기록**과 **고정비 레버**(채무 금리 7.8% · 주거 만료 2027-04).

**제안이다. 예약·알림 자동화는 만들지 않았다.**
실제로 한 일은 `execution/YYYY-MM-DD-review.md` 에 따로 적는다 — **이 문서는 계획이다.**

## 이 4주가 하는 일 하나
**지금 실측이 0 이다.** 적자는 월 206~301만 구간 추정이고, 절감이 실제로 일어나는지 볼 수단이 없다.

→ **측정 세 칸을 켜고, 한 번 정하면 끝나는 절감부터 치운다.**

| 측정 | 비용 | 무엇을 재나 |
|---|---|---|
| **월말 현금 잔액** | 월 1분 | **적자 실측.** 구간 206~301만을 숫자 하나로 대체한다 |
| 실지출 (가계부 합계 − 이체) | 월 10분 | 소비 쪽 절감 — 식비·쇼핑 60만 |
| 포커 통장 순유출 | 월 5분 | 바이인 쪽 절감 — 40만. **실지출에는 안 나타난다** |
| 수면·증상 | **하루 10초** | 안정화의 두 번째 축(FACT-0170). 지금 3일치가 전부라 추세를 말할 수 없다 |

**그리고 목적지를 적어 둔다**: 적자 0 에는 레버 전부(약 148만)로도 **117만이 모자라고**
그건 수입 축에서만 나온다([STABILIZE](../simulation/STABILIZE_20261029.md)).
**이번 90일은 거기까지 가는 길의 앞쪽이다.**

## 두 종류의 절감을 구분한다
| | 항목 | 월액 | 성질 |
|---|---|---:|---|
| **한 번 정하면 끝난다** | 통신 | 7만 | 요금제 전환 — 그 뒤로 관리 비용 0 |
| | 보험 | 10만 | 보장 점검 — **금융 판단이라 공식 근거 확인 후** |
| | 정기결제·구독 | **미확인** | 쓰지 않는 것만 — 가계부 앱에서 본인이 확인 |
| | **채무 금리 7.8%** | 이자 **월 29.9만** | 전환되면 월 4~8만 · **총이자 286~593만.** 조건 확인부터 |
| | **주거 (2027-04 만료)** | 95만 | **가장 큰 레버.** 한 번 정하면 2년. 결정 시점 **2027-01~02** |
| **매달 의지가 든다** | 식비·카페·간식 | 약 310만 | 최대 항목 |
| | 쇼핑 | 미확인 | |
| | 포커 바이인 | 약 70만(추정) | 본인 발의(FACT-0162). **포커는 불가침**(FACT-0122) |

**통신+보험은 약 17만뿐이고 100만을 못 만든다.** 그래도 **먼저 치운다** —
작아도 영구적이고 그 뒤로 의지가 들지 않는다. **안정화란 의지에 덜 의존하는 상태다.**

**금리와 주거는 금액이 다르다.** 금리는 월 4~8만이지만 **총이자 286~593만**이고,
주거는 **월 95만이 걸린 가장 큰 레버**다. 둘 다 이번 90일에는 **실행이 아니라 조건 확인**이다.
