# 실제 실행
**2026-10-29 첫 계획이 들어왔다** — [90일 실행 계획](2026-10-29-plan-90days.md) (2026-10-29 ~ 2027-01-27).

목표 셋: **G1** 월 지출 100만 절감 · **G2** 유상 거래 1건 · **G3** 포커 월별 손익 기록.
핵심은 G2 다 — 지금 계획 전체가 두 개의 감(건당 10시간·고객 확보 2~3달) 위에 서 있고,
거래 한 건이 그 둘을 동시에 실측으로 바꾼다.

**아직 실제 행동이나 결과는 입력하지 않았다.**
`YYYY-MM-DD-review.md` 를 `templates/EXECUTION_REVIEW.md` 에서 만들어 기록한다.
주간 검토는 행동·장애물·다음 3개, 월간 검토는 자금·기준점 변화, 분기 검토는 목표·경로를 다룬다.
이 주기는 운영 제안이며 예약 자동화는 생성하지 않았다.
