# 90일 기록 틀 — G1 · G2 · G3

작성: WACUS · 2026-10-29 · 근거 [90일 실행 계획](../2026-10-29-plan-90days.md)

90일 계획의 목표 셋을 **적을 자리**다. 세 파일뿐이고 더 늘리지 않는다.

**2026-10-29 우선순위가 바뀌었다** — [DEC-001](../../decisions/DEC-001-expense-first.md).

| 파일 | 순위 | 무엇이 풀리나 |
|---|---|---|
| [G1-spend.md](G1-spend.md) | **1순위 — 유일한 필수** | 월말 현금 잔액(적자 실측) · 실지출 · 한 번 끝나는 절감 |
| [G3-poker.md](G3-poker.md) | **G1 의 측정 도구** | 바이인 쪽 40만. **실지출에 안 나타나므로 따로 센다** |
| [G4-stability.md](G4-stability.md) | **안정화의 두 번째 축** | 수면·증상 추세. 2026-10-29 목표에 포함됐다(FACT-0170) |
| [G2-outreach.md](G2-outreach.md) | **후순위 — 다만 목적지에는 필수** | 건당 시간 · 고객 확보 기간 · 단가. 적자 0 에는 수입 약 117만이 필요하다 |

**세 칸을 더해야 100만이 된다** — 실지출(식비·쇼핑 60만) + 통장 순유출(바이인 40만) + 고정비 정리(영구).
그리고 **그 전부가 월말 현금 잔액 한 줄에 합쳐져 나타난다.** 그게 가장 싼 지표다.

**목적지는 적자 0 + 수면·건강**(FACT-0170 · [DEC-002](../../decisions/DEC-002-stabilization-target.md)).
레버를 전부 더해도 약 148만이고 **117만이 남는다** — 그래서 G2 는 후순위이지만 **목적지에서는 필수**다.

## 어디에 적나 — 2026-11-02 결정 (앱이 생겼다)
기록할 자리가 둘이 됐다. **양쪽에 적으면 둘 다 안 채워진다.** 하나로 가른다.

| 무엇 | 어디 | 주기 |
|---|---|---|
| **현금 잔액** | **앱** `나의 기록` | 월말 + 수시 |
| **수면·컨디션** | **앱** (퀘스트 완료로) | 매일 10초 |
| **실행·퀘스트·보상** | **앱** | 수시 |
| 월 지출 (가계부 합계·이체·실지출) | [G1-spend](G1-spend.md) | **월 1회** |
| **포커 입출금** | **앱** (`poker-out` / `poker-in` 관측) | 그때그때 |
| 포커 바이인·상금·플랫폼 잔액 | [G3-poker](G3-poker.md) | 월 1회 |
| 고정비 정리 결과 | [G1-spend](G1-spend.md) | 실행할 때 |
| 수면 **월 평균**·증상 일수 | [G4-stability](G4-stability.md) | **월 1회** (앱에서 옮겨 적는다) |
| 사실·결정·판정 | `reality/facts.json` · `decisions/` | 변화가 있을 때 |

**원칙: 매일·수시로 적는 것은 앱, 월말에 한 번 정리하는 것은 이 저장소.**
앱은 손에 있고 두 기기에서 이어지지만 **분석·판정에 약하다.** 저장소는 그 반대다.
월간 검토(11/30)는 **앱에서 숫자를 꺼내 이 표에 옮기는 자리**다.

**정정 (2026-11-02)**: 앱 모델에 **`poker-out`·`poker-in` 관측 종류가 이미 있었다.**
"앱의 기록 종류가 현금·시간·수면 셋뿐"이라고 적었던 것은 틀렸다 — 스키마를 보지 않고 쓴 말이다.
→ **통장 입출금은 앱에 적는다.** 저장소에는 바이인·상금·플랫폼 잔액처럼 앱이 담지 않는 것만 남긴다.

## 지킬 것
1. **없는 값을 0으로 채우지 않는다.** 모르면 `null` 과 사유를 적는다 (AGENTS.md).
   아직 안 한 것은 `미시작`, 재지 못한 것은 `미확인` 이다. **둘은 다르다.**
2. **관측과 해석을 섞지 않는다.** 숫자 칸에는 본 것만, 판단은 비고에.
3. **출처를 적는다.** 가계부 앱 화면 · 플랫폼 화면 · 본인 기억은 신뢰도가 다르다.
4. **개인 식별정보를 적지 않는다**(docs/PRIVACY.md). G2 대장은 **공개된 사업체명·URL 까지만** 적고
   담당자 이름·연락처는 적지 않는다.
5. 여기 적힌 값이 기준점을 바꾸면 `reality/facts.json` 에 사실로 올린다. **이 파일은 사실 대장이 아니다.**
6. **파일을 늘리지 않는다.** 네 개가 끝이다. G4 는 D-004 가 답으로 닫힌 뒤에 만들었다(FACT-0170) —
   **기준 없이 칸을 만들면 재지도 않을 표가 늘어난다.** 그 순서를 지켰다.
7. **G4 는 시간과 빈도만 적는다.** 진단·약물 판단을 결론으로 삼지 않는다(AGENTS.md).
