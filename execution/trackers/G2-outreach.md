# G2 — 아웃바운드 접촉 대장 (**후순위**)

**2026-10-29 부터 90일 필수 목표가 아니다** — [DEC-001](../../decisions/DEC-001-expense-first.md).
지출 축소가 1순위다. **이 대장은 유효하고 그대로 쓸 수 있다**: 압박과 시한만 뺐다.
**재개 기준** — 지출 절감이 **2개월 연속 목표선을 넘으면** 다시 올린다.

작성: WACUS · 절차 [아웃바운드 운영](../2026-10-29-outreach-playbook.md) · 목표 **유상 거래 1건**

**공개된 사업체명·URL 까지만 적는다.** 담당자 이름·연락처·대화 원문은 적지 않는다(docs/PRIVACY.md).

## 이 대장이 푸는 것
| 빈칸 | 대체되는 가정 |
|---|---|
| 유상 1건 실제 작업 시간 | **ASM-0017** 건당 10시간 |
| 회신 → 거래 전환 기간 | **ASM-0018** 고객 확보 2~3개월 |
| 수금까지 기간 | **ASM-0019** 작업·수금 0.5~1개월 |

**이 셋이 90일 계획 전체를 떠받치고 있다**(RUNWAY_PROBLEM: *"ASM-0017·0018 이 틀리면 이 문서 전체가 바뀐다"*).
