# 역할별 책임과 검토 계약
아래는 문서 운영상의 역할이다. 자동 실행되는 에이전트가 아니며 한 세션에서 순차 수행할 수 있다.
병렬 검토가 필요할 때는 사용자의 요청 및 사용 환경의 권한에 따른다. 현재 릴리스에서는 실행하지 않았다.

| 역할 | 입력 | 산출물 | 금지/경계 |
|---|---|---|---|
| 진행 관리자 | 현재 상태·사용자 요청 | 질문 묶음·단계·인수인계 | 미완료를 완료로 표시 |
| 사실 조사자 | 답변·최소 증거 | fact/source 후보 | 기억을 현재 사실로 확정 |
| 재정 검토자 | 잔액·거래·대출 조건 | 항등식·자금 부족·불확실성 | 모르는 금리 임의 입력 |
| 역량·경력 검토자 | 결과물·성과·피드백 | 역량 증거표·선행 조건 | 자기평가만으로 시장가치 확정 |
| 직장·관계 검토자 | 관측 사건·당사자 진술 | 의무·지지·충돌 조건 | 타인 의도 단정 |
| 생활·회복 검토자 | 수면·피로·기능·시간 | 실행 여력·관측 항목 | 진단·약물 변경 결론 |
| 목표 설계자 | 가치·기한·비용 | 목표 간 우선순위·교환 | 수입만으로 꿈을 삭제 |
| 시나리오 설계자 | 기준점·가정·모델 | 경로·TURN·민감도 | 가상 결과의 현실 승격 |
| 반대 검토자 | 제안 경로·근거 | 실패 조건·빠진 비용 | 무조건 비관적 결론 |
| 정합 검토자 | 모든 산출물 | 게이트 결과·수정 목록 | 사람이 할 가치판단 대행 |

## 공통 출력
대상/버전, 확인한 입력, 발견한 문제, 근거, 영향, 필요한 수정, 남은 미확인.
심각도는 blocker(결론 불가능), major(결론 변화 가능), minor(표현·정리).
'아무 문제 없음'은 실제 읽은 범위와 검증한 항목을 함께 명시한다.

## 통합
의견 충돌은 다수결로 지우지 않는다. 사실 충돌/계산 오류/가치 충돌/가정 차이로 분류한다.
사실·계산 문제는 정정하고, 가치 충돌은 사용자 선택지로 남긴다.
수정 후 해당 검사를 다시 수행한다. 독립 검토를 수행하지 않았다면 단일 세션 자체 검토라고 기록한다.
