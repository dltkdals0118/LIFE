# 시뮬레이션 명세 v0.1
## 시간
TURN 1은 조사 회차다. 이후 가상 진행은 SIM-001부터 별도로 번호를 붙인다.
기준점 확정 후 첫 가상 기간을 정한다. 기본 제안은 기준점 다음 날부터 해당 달력 분기 말까지의 부분 분기,
이후 1~3월/4~6월/7~9월/10~12월이다. 부분 월의 급여를 임의 일할하지 않고 실제 예정 입금·지출일을 사용한다.
종료 목표는 2036-12-31. 실제 시작일은 현재 미정이다.

## 경로와 범위
경로 A 현재 유지 / B 안정 우선 / C 성장 우선.
각각 보수적·기준·낙관 가정을 둔다. 이름만 바꾸고 같은 결과를 내지 않는다.
변수: 실수령, 필수지출, 이직 공백, 부업 순수익, 가용시간, 목표 비용, 회복 부담.
변수 선택과 범위는 조사 결과에 근거한다. 각 경로의 강점·취약 조건·지킬 가치·포기할 것을 기록한다.

## 상태 변화
1. 시작 상태를 기준점 또는 직전 TURN에서 읽는다.
2. 선택의 선행 조건과 돈·시간 자원을 확인한다.
3. 실행률(예: 50/75/100%)을 '스트레스 테스트 가정'으로 지정한다. 실제 확률이나 사용자 성격 점수가 아니다.
4. 월별 재무·시간 변화를 계산한다.
5. 관측 가능한 생활 기능과 목표 진행을 설명한다. 질병 발생/회복을 숫자로 예측하지 않는다.
6. 종료 상태와 항등식 검사를 기록한다.
7. 다음 TURN의 기초 상태를 고정한다. 뒤늦은 수정은 새 revision으로 생성한다.

## 인과와 불확실성
이직→급여, 학습→실력, 실력→수입에 시간 지연과 조건을 둔다.
학습시간만으로 연봉 상승을 자동 발생시키지 않는다. 결과물·평가·지원 결과를 중간 지표로 둔다.
선택을 보상하기 위한 성공이나 HARD MODE를 위한 불운을 만들지 않는다.
초기 버전은 결정론적 시나리오 비교다. 난수·몬테카를로는 분포 근거와 재현 seed가 준비된 뒤 별도 구현한다.
이벤트는 사용자 지정/가정된 스트레스/실제 발생으로 분류하고 서로 섞지 않는다.
연속 손실·실업·가족 지출 등 스트레스는 금액·기간·전환 조건을 제시하되 발생 확률은 근거 없이 붙이지 않는다.

## 포커 모듈
활성 여부는 현재 활동 확인 후 결정한다.
바이인·재참가·수수료·상금·출입금·플레이시간·이동비를 분리한다.
누적 순손익=상금-바이인-재참가-수수료-관련 비용. 계좌 출입금은 손익과 다르다.
기술·바이인 규모·분산·자금관리·틸트·수면 영향을 별개로 기록한다.
관측 표본이 부족하면 기대수익을 미확인으로 두고 생활비 재원으로 확정하지 않는다.
손실 만회를 위한 차입·판돈 확대를 성장 전략으로 제안하지 않는다.
목표는 실제 자금·시간 영향을 이해하는 것이며 베팅 최적화가 아니다.

## 결과 표현
각 TURN: 시작표 → 선택지와 제약 → 선택 → 월별 원장 → 종료표 → 가정 변화 → 전환 조건.
전체 인생 점수는 만들지 않는다. 현금, 부채, 의무 충족, 가용시간, 기능, 목표 진척을 병렬 표시한다.
사진·게임 묘사는 '가상 장면'으로 명시한다. 서사와 숫자가 충돌하면 원장과 가정부터 수정한다.
