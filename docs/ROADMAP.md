## M2 구현 요구
Python 표준 CLI 또는 의존성이 명확한 단순 도구로 시작한다.
읽기 검증이 기본, 자동 수정을 기본값으로 두지 않는다.
누락 값 null, ID 중복, 고아 참조, 잘못된 날짜, 금액 단위, 기준점 상태, simulated 혼입을 검사한다.
오류 메시지에는 필요한 레코드 ID만 출력하고 민감한 원문을 반복하지 않는다.

## M3/M4 구현 요구
계산 함수와 파일 입출력을 분리한다. 합성 fixture와 예상 결과를 함께 둔다.
입력 hash·모델 버전·가정 버전을 출력에 남긴다.
서로 다른 baseline/model의 결과는 동일 조건 비교가 아님을 표시한다.
실제 사용자 기록 없이도 테스트가 실행되어야 한다.

## 우선순위
P0: 조사 시작에 필요한 기록·정합·재개.
P1: 돈과 시간의 정확한 계산, 사용자 가치와 목표 연결.
P2: 분기 시뮬레이션과 실제 실행 연결.
P3: 시각화·게임 묘사·편의 자동화.
문서 수·에이전트 수·화면 수를 늘리는 자체를 목표로 삼지 않는다.
