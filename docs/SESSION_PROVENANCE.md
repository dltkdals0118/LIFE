**`evidence_raw/sessions/`** — 복원한 대화 원문과 공유 페이지 HTML 원본.

`docs/PRIVACY.md` 의 *"원문 전체보다 최소한의 요약을 우선한다"* 와
*"로컬 `evidence_raw/`는 ignore 대상이다"* 에 따라 **커밋하지 않는다.**
원문에는 재정·건강·가정사가 정리되지 않은 상태로 들어 있고,

```
evidence_raw/sessions/
  README.md                        세션 요약과 주의사항
  2026-10-28_재설계_6ae15340.md    복원 원문
  2026-10-28_검토_6ae154be.md      복원 원문
  raw/*.html                       공유 페이지 원본 — 바이트 그대로
```

로컬에만 있으므로 **PC가 바뀌면 따라오지 않는다.** 보존이 필요하면 별도로 챙긴다.

## 복원 방법 — 재현 가능하다

공유 링크는 SPA 라 일반 조회로는 제목만 나온다. 본문은 페이지 안의 react-router
turbo-stream 페이로드에 들어 있고, 저장소의 복원기로 다시 꺼낼 수 있다.

```bash
python tools/decode_chatgpt_share.py evidence_raw/sessions/raw/<id>.html
# → <id>.html.convo.txt     대화 원문
# → <id>.html.decoded.json  구조 전체
```

2026-10-28 확인: 보관된 HTML 로 다시 돌린 결과가 보관된 복원본과 **바이트까지 동일**(30,135 B).

`raw/` 를 지우면 복원의 근거가 사라진다. 대화 원문만 남기지 말 것.
