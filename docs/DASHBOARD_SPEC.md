# 대시보드 설계 — 후속 구현
상태: 명세만 작성. 웹사이트·앱·배포는 만들지 않았다.
문서와 계산이 검증된 뒤 개인용 로컬 화면부터 검토한다.

## 화면
| 화면 | 내용 | 금지할 오해 |
|---|---|---|
| 오늘 | 실제 기준일·다음 행동 3개·가까운 의무 | 미래 수치를 현재 잔액처럼 표시 |
| 현실 기준점 | 현금·부채·필수비·시간·생활 기능 | null을 0으로 시각화 |
| 조사 현황 | 영역별 확인·미확인·보류·충돌 | 조사 완료율을 인생 점수로 표현 |
| 목표 | 최소/희망 수준·기한·필요자금·선행 조건 | 비용만으로 가치 평가 |
| 경로 비교 | 같은 기준점의 3경로·가정·손실 범위 | 임의 성공 확률 표시 |
| TURN | 월별 원장·선택·가상 장면·전환 조건 | 가상과 실제 혼합 |
| 실행 | 완료/보류·실제 시간·장애물·회복 | 미완료를 도덕적 실패로 표현 |
| 변경 이력 | 기준점·가정·결정·재계산 영향 | 이전 결과를 조용히 덮기 |

## 시각 규칙
화면 상단에 REALITY 또는 SIMULATION 배지를 명시한다.
금액마다 단위와 기준일, 시나리오마다 baseline/model 버전을 표시한다.
미확인은 '미확인', 추정은 범위로 표시한다. 색상만으로 상태를 구분하지 않는다.
데이터 내려받기·외부 공유는 기본 비활성 기능으로 설계한다.
사진을 쓰면 장식/가상 장면이며 개인 사실의 근거가 아님을 표시한다.
모바일에서 표는 핵심 열 우선·상세 펼치기, 키보드 탐색·명확한 대비를 적용한다.

## 데이터 연결
화면이 따로 숫자를 계산하지 않도록 검증된 모델 결과를 읽는다.
원본 기록을 수정하면 기준점/시나리오의 갱신 필요 표시를 유지한다.
