# 재무·시간 모델 명세 v0.1
상태: 설계. 계산기는 아직 구현하지 않았으며 실제 사용자 수치를 계산하지 않았다.

## 단위와 원장
KRW 정수 원, 입력 원 단위 그대로 보존, 표시에서만 만원 환산.
자산·부채 스냅샷과 현금 거래 원장을 분리한다.
거래 필드: id, date, amount_krw(양수), direction(in/out), account_alias, category,
transfer_pair_id, liability_id, source_id, reality_or_simulation.
동일 소유 계좌 간 이체는 연결해 총 현금흐름에서 상쇄한다.

## 월별 항등식
기말 현금 = 기초 현금 + 현금 유입 - 현금 유출.
기말 대출 = 기초 대출 + 신규 차입 + 자본화 이자 - 원금 상환.
순자산 = 평가 기준일의 자산 합계 - 부채 합계.
신규 차입은 현금 유입이지만 근로·사업 소득이 아니다.
원금 상환은 현금 유출이지만 소비 비용·이자 비용과 구분한다.
현금 부족분을 자동으로 신규 차입이나 자산 매각으로 메우지 않는다. 부족 시점과 필요 결정을 표시한다.

## 카드와 자산
카드 결제는 구매 시 비용/카드 부채에 인식한다. 납부 시 현금 감소/카드 부채 감소만 기록한다.
현금흐름 표와 소비 내역 표를 별도로 보여 이중 계산을 막는다.
주식 매수는 현금 감소와 투자자산 증가, 매도는 역방향이다. 평가손익은 현금 유입과 다르다.
보증금은 자산이지만 즉시 사용 가능한 생활자금에서 제외한다.
가족 돈·사업 돈·본인 돈의 소유·사용 제한을 구분한다.

## 대출별 필수 입력
대출 별칭, 잔액 기준일, 잔액, 연이율, 고정/변동, 상환방식, 납입일, 만기,
월 납입액, 원금/이자 구분, 중도상환 조건, 실제 상환표 출처.
금리·상환방식이 미확인이면 정밀 상환 경로는 계산 보류. 범위 시나리오는 가정을 명시한다.
실제 금융기관 상환표가 있으면 계약상 일정이 우선한다.

## 단순 월 모델
P=월초 원금, r=연이율/12, n=남은 월수.
원리금균등: A=P*r/(1-(1+r)^(-n)); r=0이면 P/n.
당월 이자=P*r; 원금 상환=min(P, A-이자).
원금균등: 약정 원금 분할액+당월 이자.
만기일시: 약정 기간 이자 납부, 만기 원금 전액 상환.
이는 비교용 월 모델이다. 일할 계산·납입일·반올림·수수료·변동금리·연체는 별도 계약 입력이 필요하다.
반올림 정책은 월별 원 단위, 마지막 회차 잔여 원금 조정으로 기록하고 실제 상환표와 오차를 표시한다.
상환액<이자라면 정상 상환처럼 원금을 음수로 감소시키지 않고 미납/자본화 조건 확인 상태로 처리한다.

## 필요한 돈
목표별 일회 비용과 반복 비용을 분리한다.
기한까지 필요자금 = 일회 비용 + 해당 기간 반복 비용 + 사용자가 정한 예비자금.
필요자금 부족분에는 자산 처분의 시점·제약과 기존 의무를 반영한다.
비상자금 개월 수나 투자수익률은 임의 확정하지 않는다.
물가·연봉·수익률은 출처 있는 가정 또는 명시적 탐색 범위이며 명목/실질 기준을 표시한다.

## 시간 모델
주 168시간 = 수면 + 노동 + 통근 + 가사/돌봄 + 식사/위생 + 회복 + 여가 + 학습/부업 + 미분류.
서로 겹치는 활동을 이중으로 차감하지 않는다.
관측된 시간과 희망 시간을 나란히 비교한다. 이동 중 학습시간을 무조건 온전한 집중시간으로 환산하지 않는다.
계획 시간이 168시간을 넘으면 불가능. 남는 시간을 전부 생산적 활동에 배정하지 않는다.

## 후속 구현 필수 테스트
- 잔액 0과 미확인 null 구분; 음수 소득 등 부적절한 입력 거절.
- 무이자, 원리금균등, 원금균등, 만기일시, 마지막 상환, 수수료.
- 원금 상환과 이자 비용 분리; 신규 차입의 소득 오분류 차단.
- 카드 구매/납부 및 계좌 이체 이중계상 방지.
- 현금 부족·만기 목돈·자산 매각 시점 표시.
- 월별 기말이 다음 달 기초와 일치; 총부채와 대출별 합계 일치.
- 같은 입력·모델 버전은 같은 결과.
테스트 데이터는 합성 자료로만 만든다.
