# 개인정보와 변경 이력
## 저장 범위
LIFE는 전용 비공개 저장소다. 기록할 때마다 원문 전체보다 설계에 필요한 최소한의 요약을 우선한다.
재정·건강·가족의 정리된 사실은 사용자가 이 프로젝트에 제공한 범위에서 기록한다.
과거 기억에서 발견한 민감한 내용은 별도 재확인 전 자동 수입하지 않는다.

## 저장하지 않는 것
비밀번호·인증키·토큰·주민등록번호·전체 계좌/카드번호·원본 신분증·원본 진료/금융 증빙.
가족·동료는 역할 별칭으로 기록한다. 불필요한 실명·연락처·주소는 저장하지 않는다.
증빙은 읽고 필요한 수치와 확인 방법만 남긴다. 로컬 evidence_raw/는 ignore 대상이다.

## 공개 범위
공개 저장소 전환, GitHub Pages 배포, 외부 공유를 기본 작업으로 실행하지 않는다.
추후 요약을 공개한다면 별도 익명화 사본을 만든다. 원본 비공개 이력과 분리한다.
README·커밋 제목·이슈 제목·자동화 로그에도 민감한 내용을 넣지 않는다.

## 삭제와 정정
일반 정정은 supersedes 관계로 이력을 남긴다.
개인정보 삭제 요청은 이력 보존보다 우선한다. Git의 현재 파일 삭제만으로 과거 커밋이 지워지지 않는다.
민감정보가 커밋되면 추가 유출을 멈추고 노출 범위·이력 정리·필요한 인증정보 교체를 별도 처리한다.
히스토리 재작성은 다른 복제본에 영향을 주므로 실제 범위를 확인하고 수행한다.
.gitignore는 이미 추적된 파일이나 GitHub API로 직접 생성한 파일을 보호하지 않는다.

## 자동화 구현 시
합성 테스트 데이터만 CI에 사용한다. 개인 기록 전체를 로그·실패 메시지에 출력하지 않는다.
개인정보 검사기는 보조 수단이다. 모든 민감정보를 탐지한다고 보장하지 않는다.
