# 검수와 전환 기준
통과 기준은 데이터와 판단의 품질에 관한 것이다. 사람의 삶에 합격/불합격을 매기지 않는다.

| 관문 | 요구사항 | 실패 시 |
|---|---|---|
| G0 기록 가능 | 비공개 대상 확인, 원본/인증정보 제외, 범위 명확 | 해당 정보 제거·축약 |
| G1 사실 정합 | 날짜·단위·출처·kind, 중복·충돌 명시 | 해당 레코드 disputed/unknown |
| G2 기준점 | 핵심 재무·의무·시간, 사용자 검토, 미확인 영향 명시 | draft/conditional 유지 |
| G3 모델 | 항등식, 기간 연속, 가정과 계산 분리 | 관련 결과 산출 보류 |
| G4 시나리오 | 기준점/모델 버전, 자원 제약, 전환 조건, 실행률 비교 | 경로 수정 |
| G5 실행 | 완료 기준·기한·돈·시간·관측 방법 | 행동을 더 작게 구체화 |
| G6 커밋 | 변경 범위·링크·개인정보·상태·원격 저장 확인 | 수정 또는 미완료 보고 |

## G2의 핵심 입력
동일 기준일의 사용 가능한 현금, 부채 목록, 세후 수입, 필수 지출, 상환/만기, 12개월 내 의무,
주간 시간 제약, 생활 기능, 우선 목표.
미확인 범위가 결론을 바꿀 수 있으면 confirmed로 정밀 예측하지 않는다.
본인 진술만으로도 출처와 한계가 분명하면 기준점에 포함할 수 있다. 모든 항목에 원본 증빙을 강요하지 않는다.

## 필수 반대 검토
- 수입 1개월 지연 시 어떤 의무가 먼저 흔들리는가?
- 계획의 절반만 실행하면 어떤 효과가 남는가?
- 가장 민감한 가정 3개를 바꾸면 선택 순위가 바뀌는가?
- 목표 달성에 필요한 시간과 회복 시간을 동시에 확보할 수 있는가?
- 이 결론은 상민이 원한 목표를 반영하는가, 분석자가 대신 정한 목표인가?

## 검토 보고
대상 버전 / 검사 항목 / 결과(pass, revise, conditional, not_tested) / 근거 / 남은 문제 / 다음 행동.
구조·링크 검사 통과는 재무 모델 정확성이나 삶의 계획 타당성 검증을 의미하지 않는다.
