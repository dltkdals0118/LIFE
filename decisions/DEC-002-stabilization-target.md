# DEC-002 — '생활 안정화'를 적자 0 + 수면·건강으로 확정
- 날짜: 2026-10-29
- 상태: selected
- baseline_id / scenario_id: BASE-20261028-v1 / 90일 계획 2026-10-29
- 결정자: **사용자** (SRC-049 · FACT-0170)
- 선행 결정: [DEC-001](DEC-001-expense-first.md) — 이 결정으로 **DEC-001 의 가정이 닫혔다**

## 결정할 문제
DEC-001 은 '생활 안정화'를 **재무 안정으로 읽고** 진행했다. 가정이었고 D-004 로 열어 뒀다.
답이 왔다: **"적자 0, 수면 건강 안정화까지."**

**그래서 무엇이 바뀌는가.**

## 대안과 교환
답 자체는 사용자가 정했으므로 대안은 **그 답을 어떻게 계획에 넣는가**다.

| 대안 | 근거 | 포기할 것 | 되돌릴 수 있는 정도 |
|---|---|---|---|
| **A. 적자 0 은 목적지, 순서는 지출 먼저** ← 선택 | FACT-0169('지출 먼저')와 FACT-0170('적자 0')이 **목적지와 순서로 읽으면 충돌하지 않는다** | 적자 0 도달 시점이 90일 밖으로 나간다 | 완전히 |
| B. 적자 0 을 90일 목표로 | 목표가 선명해진다 | **달성 불가다.** 레버 전부 더해도 148만이고 117만이 남는다. 못 할 목표는 측정을 망친다 | — |
| C. 안정화를 런웨이 연장으로 완화 | 90일 안에 닫힌다 | **본인이 적자 0 이라고 답한 것을 우리가 바꾸는 것** | — |

## 선택과 이유
**A 를 선택했다.**

### 적자 0 에는 수입이 필수다 — 레버를 전부 더해 봤다
| 레버 | 월 효과 | 언제 |
|---|---:|---|
| 지출 절감 (본인 확인) | 100만 | 11월부터 |
| 통신 + 보험 정리 | 약 17만 | 11월 |
| 채무 금리 전환 7.8 → 5.0% | 약 6만 | 조건 확인 후 |
| 주거 이사 (**가정** 25만) | 25만 | 2027-04 |
| **합계** | **약 148만** | |
| **남는 적자** | **약 117만** | |

→ **전부 해도 117만이 남는다.** 런웨이는 2.3 → 5.1개월이 되지만 **적자는 0 이 되지 않는다.**
→ **적자 0 을 택했으므로 수입 축(G2)은 선택이 아니라 필수다.** 월 약 117만 — 건당 100만이면 월 1.2건.

**그래도 DEC-001 의 순서는 유지한다.** 지출·고정비는 **지금 할 수 있고 시간이 거의 들지 않는다**(행동 대부분 10분 이하).
수입 축은 시간이 든다. **순서를 바꿀 이유가 아니라, 목적지를 적어 둘 이유다.**

### 두 목표가 서로 당긴다 — 평균내지 않는다
수면·건강이 목표에 들어오면 **시간이 목표 변수가 된다.**
하루가 21.7~22.7시간 차 있고 근무·통근은 고정이며 **포커는 불가침**(FACT-0122)이다.
→ 수면을 늘릴 여지는 **부업 시간을 쓰지 않는 것**에서 나온다.
→ 그런데 적자 0 은 수입 117만을 요구한다.

| | 지금 90일 | 수입 축을 올릴 때 |
|---|---|---|
| 충돌하나 | **아니다.** 지출·고정비 행동은 10분 이하다 | **그렇다.** 주 7.9~9.9시간이 필요하다 |
| 그때 할 일 | 둘 다 진행 | **선택지를 둘로 적어 올린다.** 우리가 고르지 않는다 |

**지금 섞어서 결정하지 않는다.** 충돌 시점이 오면 그때 선택지로 만든다.

### 90일 목표에 추가되는 것
| | |
|---|---|
| **고정비 레버 확보** | 통신·보험 **실행** · 채무 금리 **조건 확인** · 주거 **이사 판단 자료** |
| **수면·건강 기록 개시** | [trackers/G4-stability.md](../execution/trackers/G4-stability.md). 목표 수치는 미정 |

**주거가 90일의 숨은 산출물이다.** 만료 2027-04 이고 결정은 통상 **2027-01~02**,
90일 종료일이 **2027-01-27** 이다. 한 번 정하면 2년이 결정되고 월 95만의 일부가 적자 117만에 직접 들어간다.

## 불확실성과 재검토
| | |
|---|---|
| **가정** | 주거 절감 **25만은 가정이다** — 매물을 보지 않았다. 빼면 필요 수입은 **142만** |
| 〃 | 금리 전환이 **가능한지 자체가 미확인**이다. 대출 종류·중도상환수수료·신용 조건 전부 모른다 |
| 〃 | '내년 4월까지'를 **계약 만료일**로 읽었다. 갱신 통보 기한은 계약서로 확인할 것 |
| 실패 신호 | 11·12월에 **고정비 레버가 하나도 실행되지 않는다** → 의지가 드는 쪽만 남는다 |
| 〃 | 수면 기록이 **2주 이상 비어 있다** → 건강 축이 목표에서 조용히 사라진다 |
| 중단·전환 기준 | **현금 300만 아래** → 수입 축을 올릴지 고정비 구조를 당길지 사람이 결정한다 |
| 〃 | 절감이 **2개월 연속 목표선을 넘으면** G2 를 올린다 (DEC-001 그대로) |
| 검토일 | **2026-11-30** · 주거는 **2026-12-31** 에 한 번 더 (결정 시점이 1~2월이다) |
| 실제 결과 | **미시작** |
