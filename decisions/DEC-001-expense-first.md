# DEC-001 — 지출 축소·생활 안정화를 1순위로, 유상 거래를 후순위로
- 날짜: 2026-10-29
- 상태: selected
- baseline_id / scenario_id: BASE-20261028-v1 / 90일 계획 2026-10-29
- 결정자: **사용자** (SRC-048 · FACT-0169)
- **2026-10-29 보강** — D-004 가 답으로 닫혔다(적자 0 + 수면·건강, FACT-0170).
  **이 결정의 순서는 유지된다**: 지출 먼저. 다만 **적자 0 은 수입 없이 닿지 않는다**는 것이 산술로 확정됐다.
  → [DEC-002](DEC-002-stabilization-target.md) 를 함께 읽는다.

## 결정할 문제
90일 계획의 핵심이 **G2 유상 거래 1건**이었다. 계획 전체가 두 개의 감
(건당 10시간 ASM-0017 · 고객 확보 2~3개월 ASM-0018) 위에 서 있고 거래 한 건이 그 둘을 실측으로 바꾸기 때문이다.

사용자가 방향을 바꿨다: *"지금은 지출이 많이 큰 상황이니까 큰 목표보다 우선 지출을 줄이고 생활 안정화 시킬 수 있는 방향으로 가자."*

**무엇을 1순위로 두고 무엇을 뒤로 미루는가.**

## 대안과 교환
| 대안 | 근거 | 돈·시간 | 포기하는 것 | 되돌릴 수 있는 정도 |
|---|---|---|---|---|
| **A. 지출 1순위 · G2 후순위** ← 선택 | 지금 실측이 0 인 상태에서 **가장 싸고 확실한 행동**이다. 주 7.9~9.9시간이 회복으로 돌아간다 | 추가 비용 0 · 주 1~2시간 | 첫 거래 시점이 밀린다. **ASM-0017·0018 이 가정으로 남는다** | **완전히.** 언제든 G2 를 올릴 수 있다 |
| B. 둘 다 유지 | 런웨이 안에 수입 축이 생긴다 | 주 7.9~9.9시간 | 수면·회복. 하루가 이미 21.7~22.7시간 차 있다 | 완전히 |
| C. G2 삭제 | 가장 단순하다 | 0 | **지출만으로는 적자 0 에 닿지 않는다**(165만 부족). 런웨이가 끝나면 남는 것이 없다 | 되돌리려면 영업을 처음부터 |

## 선택과 이유
**A 를 선택했다 — 사용자 지시 그대로다.**

C 를 고르지 않은 이유를 함께 남긴다. 산술이 이렇다([STABILIZE_20261029](../simulation/STABILIZE_20261029.md)):

| | |
|---|---:|
| 월 총유출 | 약 552만 (현금 역산·가계부 교차 검증 2.2% 일치) |
| 월 수입 | 285만 |
| 적자 0 에 필요한 절감 | **265만** |
| 본인이 가능하다고 한 선 | **100만** |
| 남는 것 | **165만** |

**지출 축소는 시간을 사는 수단이고 끝내는 수단이 아니다.**
100만 절감은 런웨이를 2.3 → 3.6개월로 늘린다. 165만은 수입·고정비 구조·기간 중 하나가 맡아야 한다.
→ 그래서 **G2 를 삭제하지 않고 후순위로 내렸다.** 압박을 빼고 시한 목표에서 뺐을 뿐이다.

### 목표 역할 재정의
| | 전 | 후 |
|---|---|---|
| G1 지출 100만 절감 | 1/3 | **유일한 필수 목표** |
| G2 유상 거래 1건 | **핵심** | **후순위 — 90일 필수에서 뺀다.** 여력이 있을 때만 |
| G3 포커 월별 손익 | 보조 | **G1 의 측정 도구.** 절감 100만의 40%가 바이인이고 실지출에 안 나타난다 |

## 불확실성과 재검토
| | |
|---|---|
| ~~가정~~ → **확정** | '생활 안정화' = **적자 0 + 수면·건강**(FACT-0170). 재무 안정으로만 읽은 것은 **범위가 좁았다.** DEC-002 가 그 귀결을 다룬다 |
| 실패 신호 | 11·12월 월말 현금 잔액이 **월 200만 이상 계속 줄어든다** → 100만 절감이 실제로 일어나지 않고 있다 |
| 〃 | 고정비 정리(통신·보험)가 **한 번도 실행되지 않는다** → 의지가 필요한 쪽만 남아 유지되지 않는다 |
| 중단·전환 기준 | **지출 절감이 2개월 연속 목표선을 넘으면 G2 를 다시 올린다.** 안정화가 목적이었고 달성되면 다음 축이 필요하다 |
| 〃 | 반대로 현금이 **300만 아래로 내려가면** 절감만으로는 늦다 — 그 시점에 G2 또는 고정비 구조(이사·채무 조건)를 사람이 결정한다(H 단계) |
| 검토일 | **2026-11-30** (첫 월간 검토) |
| 실제 결과 | **미시작.** 기록은 `execution/trackers/` |

**포커는 불가침 제약이다**(FACT-0122). 바이인 40만 축소는 **본인이 스스로 꺼낸 것**이고(FACT-0162)
우리는 포커 축소를 제안하지 않는다. 이 결정으로도 그 선은 바뀌지 않는다.
