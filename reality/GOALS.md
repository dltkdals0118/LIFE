## 원하는 삶 (FACT-0119)
| | |
|---|---|
| **자율성** | 하고 싶은 것을 하고, 하기 싫은 것을 안 할 수 있는 상태 |
| **인격** | 인간적으로 성품이 좋은 사람 |
| **관계** | 많지 않아도 좋은 것을 함께 나눌 수 있는 사람들, 그리고 파트너 |
| **경제** | 이미 안정돼 걱정이 없는 상태 |

넷 다 **상태**이지 수단이 아니다. 직업·거주지·소득 형태를 특정하지 않았으므로
설계가 그것을 대신 정하지 않는다. 말한 순서를 우선순위로 읽지도 않는다 — 묻지 않았다.

## 하고 싶은 것 (FACT-0120)
좋아하는 것: **음악 · 미술 · 포커**
돈이 있다면: **앨범 발매 · 책 출간 · 포커 대회 출전**

셋 다 **소비가 아니라 산출**이다 — 듣고 보고 치는 것이 아니라 내고 쓰고 나가는 것이다.
규모·비용은 미확인. 기한은 10년이고(FACT-0126), **직업으로 삼을 생각은 아니다**(FACT-0125·0127).

## 포기할 수 없는 것 (FACT-0122)
> **돈과 포커**

**이것은 설계 제약이고 협상 대상이 아니다.**
앞으로 어떤 계획에서도 포커를 줄이거나 끊는 것을 조치로 제안하지 않는다.

다만 **두 제약이 지금 구조에서 서로를 밀어낸다**는 것은 적어 둔다.
포커는 현재 비용 항목이고(10월 바이인 원가 하한 ₮2,561), 돈은 월 261만원씩 줄고 있다.
**이것은 모순이 아니라 설계가 풀어야 할 조건이다** — 포커를 건드리지 않고 적자를 닫을
방법이 있는지가 다음 질문이 된다.

'돈'이 무엇을 뜻하는지(지금의 현금인지, 장기 안정인지, 둘 다인지)는 아직 모른다.

## 기한·직업·포커의 위치 (2026-10-29 추가, FACT-0125~0127)
| | |
|---|---|
| **기한** | **10년** (2036년까지) |
| **직장** | **그만두지 않는다.** 라이트한 마음으로, 워라밸 챙기며 다니고 싶다 |
| **포커** | **헤비한 취미** — 직업 후보가 아니다 |

**직장을 유지한다는 것이 전제를 바꾼다.** 32억은 "일을 안 해도 되는 돈"일 필요가 없다.
그리고 2027년 1~3월 퇴사 의향(FACT-0086)은 **은퇴가 아니라 이직**이다.
포커는 수입 축이 아니라 지출·여가 축이다 — 설계에서 포커 수익을 재원으로 잡지 않는다.

## 필요 자금 (FACT-0121·0128)
> **32억 정도라고 생각하는데 사실 잘 모르겠습니다**
> **사실 큰 계산은 안했어. 너가 해줘도 좋을 것 같아.**

본인 확인으로 **검토 대상이지 확정 목표가 아니라는 것이 굳어졌다.**
산술 검토 → **[simulation/GOAL_FEASIBILITY_20261029.md](../simulation/GOAL_FEASIBILITY_20261029.md)**
(그 문서의 숫자는 전부 `simulated` 이므로 이 파일에 값으로 올리지 않는다.)

**검토 요약** — 결론을 내리지 않고 선택지만 만들었다.
- 10년에 32억 → 월 **1,872~2,683만원** 적립 필요 = 현재 수입의 **6.6~9.4배.** 급여 저축으로는 불가능.
- 월 200만 저축(생활비 85만으로 사는 수준)으로도 10년 뒤 3.26억 — **목표의 10%.**
- **일을 완전히 그만두는 데 필요한 자산조차 6.9~16.5억**으로 32억의 21~51% 다.
  그런데 일은 계속 한다고 했으므로 이 금액조차 전부 필요하지 않다.
- → **32억은 말한 삶보다 큰 숫자일 가능성이 높다.** 다만 노후·주거 매입·가족처럼
  아직 묻지 않은 항목이 그 안에 있을 수 있어 **틀렸다고 단정하지 않는다**(Q-037).

32억이 무엇을 뜻하는지는 인출률 가정이 있어야 말할 수 있다.

### ASM-0001 — 안전 인출률
| | |
|---|---|
| variable | `safe_withdrawal_rate` |
| value | 4% / 년 |
| category | **modeling** (사용자 선택도, 공식 근거도 아니다) |
| rationale | 은퇴 자금 논의에서 널리 쓰이는 어림. **한국 세제·물가·수명에 맞춰 검증한 값이 아니다.** |
| 쓰임 | 목표 금액의 의미를 가늠하는 용도. 이 가정으로 실제 재무 결정을 하지 않는다. |
| reviewed_at | 2026-10-29 |
| expires_at | 공식 근거로 대체될 때 |

이 가정 아래 **32억 = 연 1.28억 = 월 약 1,067만원**을 평생 쓰는 수준이다.
현재 월 실지출(394~549만원)의 약 2~2.7배다.

→ 2026-10-29 계산을 돌렸다. 같은 가정에서 **지금 생활을 그대로 유지하며 일을 그만두는 데
필요한 자산은 11.8~16.5억**이고, 식음료를 조정하면 9.9억, 고정비만 쓰면 6.9억이다.
**32억은 그 2~4.6배다.**

## 지금 어디에 있나 (FACT-0123)
| | |
|---|---:|
| 현재 순자산 | 약 **−2,000만원** (현금 600 + 보증금 2,000 − 채무 4,600) |
| 목표 | 32억 |
| **격차** | **약 32.2억** |
| 현재 월 변화 | **−261만원** |

**지금 방향은 목표의 반대 방향이다.** 평가가 아니라 두 숫자의 부호다.

규모 감각 (이자 제외):
- 월 100만원 × 30년 = 3.6억
- 월 500만원 × 30년 = 18억

**근로소득 저축만으로 32억에 닿는 경로는 현실적으로 없다.** 10년 기한에서는 더욱 그렇다 —
필요 월 적립이 1,872~2,683만원으로 현재 수입의 6.6~9.4배다.

선택지는 넷이고 **고르는 것은 사용자다.** 설계는 선택지를 만들 뿐이다.

| | 무엇 | 대가 |
|---|---|---|
| A | **목표 금액 재검토** — 말한 삶의 비용을 아래에서 위로 계산 | 32억이라는 상을 내려놓아야 할 수 있다 |
| B | **기한 연장** — 10년 → 20·30년 | 부담은 줄지만 급여만으로는 여전히 벅차다 |
| C | **소득 구조 변경** | **"라이트하게·워라밸"과 정면 충돌** |
| D | 조합 | |

**A·B·C 중 무엇을 고르든 1번 관문(월 적자 261만 → 0)은 똑같이 선행한다.**
그리고 그건 선택이 아니라 **현금 2.3개월**이라는 시한이 붙어 있다.

## 포커를 건드리지 않고 적자를 줄일 수 있는 자리 (FACT-0124)
제약(포커 불가침)을 지킨 채 월 261만원을 어디서 줄일 수 있는지, 크기순으로.

| 항목 | 월 | 조정 여지 |
|---|---:|---|
| **카페·간식 + 식비** | **182~281만** | **재량 덩어리 중 압도적으로 크다** |
| 주거 | 95만 | 이사 비용·보증금이 묶여 바로 움직이기 어렵다 |
| 채무 상환 | 80만 | 줄이면 이자가 늘어 장기적으로 손해다 |
| 어머니 지원·보험·통신·교통 | 합 54만 | 성격상 조정 폭이 작다 |

10월 식음료 281만원을 월 100만원 수준으로 낮추면 **약 181만원**이 생긴다 — 적자의 70% 안팎이다.

**이것은 관측이지 지시가 아니다.** 실제로 줄일지, 얼마나 줄일지, 그것이 삶의 질에
어떤 뜻인지는 사용자가 정한다. 여기 적는 이유는 **포커를 건드리지 않고도 큰 자리가
하나 남아 있다**는 사실이 선택지를 넓히기 때문이다.

## 풀리지 않은 충돌 하나
**"10년에 32억"과 "라이트하게·워라밸"이 정면으로 부딪친다.**
32억을 10년 안에 원하면 소득 구조를 바꿔야 하고, 그건 한동안 라이트할 수 없다는 뜻이다.
워라밸을 지키면 32억·10년은 성립하지 않는다.

**둘 다 본인이 말한 것이므로 어느 쪽을 바꿀지는 본인만 정할 수 있다.**
설계는 이 충돌을 평균내거나 숨기지 않는다.

## 아직 묻지 않은 것
- 32억 안에 **주거 매입·결혼·자녀·부모 부양·노후**가 들어 있는지 (Q-037)
- 앨범·책·대회의 **실제 비용**과 최소 수준
- "라이트하게·워라밸"의 구체적 기준 — 주당 근무시간, 수용 가능한 연봉 범위
- 각 목표의 **우선순위** (기한은 받았다)
- 현재 직장에서 **소득이 오를 여지**, 퇴직연금·국민연금 등 **이미 쌓이고 있는 것**
- 파트너·관계에 대해 원하는 것의 구체적 모습 (본인이 말한 범위 밖은 묻지 않는다)
