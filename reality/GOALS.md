# 목표 v0.1 — 2026-10-29

작성: WACUS · 근거: 본인 진술(SRC-036) · 상태: draft, 기한·우선순위 미확정

이 문서는 **원하는 상태**를 적는다. 그것을 어떻게 이룰지(경로)는 `simulation/` 이 맡고,
아직 만들지 않았다.

## 원하는 삶 (FACT-0119)
| | |
|---|---|
| **자율성** | 하고 싶은 것을 하고, 하기 싫은 것을 안 할 수 있는 상태 |
| **인격** | 인간적으로 성품이 좋은 사람 |
| **관계** | 많지 않아도 좋은 것을 함께 나눌 수 있는 사람들, 그리고 파트너 |
| **경제** | 이미 안정돼 걱정이 없는 상태 |

넷 다 **상태**이지 수단이 아니다. 직업·거주지·소득 형태를 특정하지 않았으므로
설계가 그것을 대신 정하지 않는다. 말한 순서를 우선순위로 읽지도 않는다 — 묻지 않았다.

## 하고 싶은 것 (FACT-0120)
좋아하는 것: **음악 · 미술 · 포커**
돈이 있다면: **앨범 발매 · 책 출간 · 포커 대회 출전**

셋 다 **소비가 아니라 산출**이다 — 듣고 보고 치는 것이 아니라 내고 쓰고 나가는 것이다.
규모·비용·기한은 미확인이고, 직업으로 삼을 생각인지도 아직 묻지 않았다.

## 포기할 수 없는 것 (FACT-0122)
> **돈과 포커**

**이것은 설계 제약이고 협상 대상이 아니다.**
앞으로 어떤 계획에서도 포커를 줄이거나 끊는 것을 조치로 제안하지 않는다.

다만 **두 제약이 지금 구조에서 서로를 밀어낸다**는 것은 적어 둔다.
포커는 현재 비용 항목이고(10월 바이인 원가 하한 ₮2,561), 돈은 월 261만원씩 줄고 있다.
**이것은 모순이 아니라 설계가 풀어야 할 조건이다** — 포커를 건드리지 않고 적자를 닫을
방법이 있는지가 다음 질문이 된다.

'돈'이 무엇을 뜻하는지(지금의 현금인지, 장기 안정인지, 둘 다인지)는 아직 모른다.

## 필요 자금 (FACT-0121)
> **32억 정도라고 생각하는데 사실 잘 모르겠습니다**

본인도 확신하지 않는 값이라 **목표로 고정하지 않고 검토 대상으로 둔다.**

32억이 무엇을 뜻하는지는 인출률 가정이 있어야 말할 수 있다.

### ASM-0001 — 안전 인출률
| | |
|---|---|
| variable | `safe_withdrawal_rate` |
| value | 4% / 년 |
| category | **modeling** (사용자 선택도, 공식 근거도 아니다) |
| rationale | 은퇴 자금 논의에서 널리 쓰이는 어림. **한국 세제·물가·수명에 맞춰 검증한 값이 아니다.** |
| 쓰임 | 목표 금액의 의미를 가늠하는 용도. 이 가정으로 실제 재무 결정을 하지 않는다. |
| reviewed_at | 2026-10-29 |
| expires_at | 공식 근거로 대체될 때 |

이 가정 아래 **32억 = 연 1.28억 = 월 약 1,067만원**을 평생 쓰는 수준이다.
현재 월 실지출(394~549만원)의 약 2~2.7배다.

→ 앨범·책·대회를 하면서 "걱정 없는" 상태를 뜻한다면 터무니없는 숫자는 아니다.
다만 **이 금액이 그 삶에 정말 필요한 액수인지는 아직 아무도 계산하지 않았다.**

## 지금 어디에 있나 (FACT-0123)
| | |
|---|---:|
| 현재 순자산 | 약 **−2,000만원** (현금 600 + 보증금 2,000 − 채무 4,600) |
| 목표 | 32억 |
| **격차** | **약 32.2억** |
| 현재 월 변화 | **−261만원** |

**지금 방향은 목표의 반대 방향이다.** 평가가 아니라 두 숫자의 부호다.

규모 감각 (이자 제외):
- 월 100만원 × 30년 = 3.6억
- 월 500만원 × 30년 = 18억

**근로소득 저축만으로 32억에 닿는 경로는 현실적으로 없다.** 따라서 선택지는 셋이다.

1. **목표 금액 재검토** — 32억이 정말 필요한 액수인지 계산해 본다
2. **소득 구조 변경** — 사업·지분·고소득 전문성 등 급여 외의 축
3. **둘 다**

**어느 쪽인지는 사용자가 정한다.** 설계는 선택지를 만들 뿐 고르지 않는다.

## 포커를 건드리지 않고 적자를 줄일 수 있는 자리 (FACT-0124)
제약(포커 불가침)을 지킨 채 월 261만원을 어디서 줄일 수 있는지, 크기순으로.

| 항목 | 월 | 조정 여지 |
|---|---:|---|
| **카페·간식 + 식비** | **182~281만** | **재량 덩어리 중 압도적으로 크다** |
| 주거 | 95만 | 이사 비용·보증금이 묶여 바로 움직이기 어렵다 |
| 채무 상환 | 80만 | 줄이면 이자가 늘어 장기적으로 손해다 |
| 어머니 지원·보험·통신·교통 | 합 54만 | 성격상 조정 폭이 작다 |

10월 식음료 281만원을 월 100만원 수준으로 낮추면 **약 181만원**이 생긴다 — 적자의 70% 안팎이다.

**이것은 관측이지 지시가 아니다.** 실제로 줄일지, 얼마나 줄일지, 그것이 삶의 질에
어떤 뜻인지는 사용자가 정한다. 여기 적는 이유는 **포커를 건드리지 않고도 큰 자리가
하나 남아 있다**는 사실이 선택지를 넓히기 때문이다.

## 아직 묻지 않은 것
- 각 목표의 **기한**과 **우선순위**
- "하고 싶은 것"의 **최소 수준** (앨범 1장인지 음악으로 먹고사는 것인지)
- 앨범·책·대회의 **실제 비용**
- '돈'이 뜻하는 것 — 지금의 현금 안정인지, 장기 자산인지, 둘 다인지
- 포커가 **취미인지 직업 후보인지** (FACT-0120 에 '대회 출전'이 있으므로 갈림길이다)
- 파트너·관계에 대해 원하는 것의 구체적 모습 (본인이 말한 범위 밖은 묻지 않는다)
